Die Datenbank des EinsatzMonitors kann im Laufe der Zeit stark anwachsen. Das führt dazu, dass der EinsatzMonitor länger zum Starten braucht. Mit dieser Anleitung reduzieren Sie die Größe der Datenbank auf ein notwendiges Minimum, indem Sie unnötige Logeinträge entfernen. Außerdem erfahren Sie, wie Sie den Fahrzeug- und den Benutzer-Cache leeren.

## Datenbankstandort

Die SQLite-Datenbank des EinsatzMonitors befindet sich hier:

```
%USERPROFILE%\Einsatz_Monitor\EinsatzMonitor.sqlite
```

also z. B. `C:\Users\<Username>\Einsatz_Monitor\EinsatzMonitor.sqlite`.

::callout{type="warning"}
**Erstellen Sie vor jeder Änderung ein Backup der Datenbank**, indem Sie die Datei bei beendetem EinsatzMonitor kopieren und an anderer Stelle einfügen. In der Datenbank liegen auch alle Einstellungen des EinsatzMonitors (Connect-Zugangsdaten, Alarmablauf, AAO usw.).
::

## Voraussetzung: DB Browser for SQLite

Zum Bearbeiten der Datenbank benötigen Sie einen SQLite-Browser, z. B. den kostenlosen **DB Browser for SQLite**:

[https://sqlitebrowser.org/dl/](https://sqlitebrowser.org/dl/)

Beenden Sie den EinsatzMonitor, bevor Sie die Datenbank öffnen.

## Alte Logeinträge entfernen

::callout{type="info"}
Der EinsatzMonitor löscht Logeinträge, die älter als 3 Tage sind, automatisch – beim Start und anschließend alle 30 Minuten. Die Datenbankdatei wird dadurch aber nicht kleiner. Um die Datei tatsächlich zu verkleinern, muss die Datenbank wie unten beschrieben komprimiert werden.
::

1. Öffnen Sie die Datenbank des EinsatzMonitors (`EinsatzMonitor.sqlite`) im DB Browser for SQLite

![Datenbank im DB Browser for SQLite öffnen](/images/einsatzmonitor/SQLBrowser_DB_open.png)

2. Wechseln Sie auf den Reiter **SQL ausführen** und geben Sie folgendes SQL-Statement ein:

```sql
DELETE from LOG
```

![SQL-Statement DELETE from LOG im Reiter SQL ausführen](/images/einsatzmonitor/SQLBrowser_DB_deleteLog.png)

3. Führen Sie das Statement über den **Play-Button** aus. Bei Erfolg erhalten Sie die Meldung, dass die Abfrage erfolgreich ausgeführt wurde und wie viele Zeilen gelöscht wurden.

![Erfolgsmeldung nach dem Ausführen des SQL-Statements](/images/einsatzmonitor/SQLBrowser_DB_deleteLog2.png)

4. Schreiben Sie die Änderungen in die Datenbank: **Datei → Änderungen schreiben**

![Menü Datei – Änderungen schreiben](/images/einsatzmonitor/sqlbrowser_db_deletelog3.png)

5. Komprimieren Sie die Datenbank: **Werkzeuge → Datenbank komprimieren…**

![Menü Werkzeuge – Datenbank komprimieren](/images/einsatzmonitor/sqlbrowser_db_deletelog4.png)

6. Markieren Sie im folgenden Dialog alle Einträge und klicken Sie auf **OK**

![Dialog Datenbank komprimieren mit allen Einträgen markiert](/images/einsatzmonitor/sqlbrowser_db_deletelog5.png)

Die Dateigröße der Datenbank sollte nun deutlich gesunken sein und der EinsatzMonitor schneller starten.

::callout{type="warning"}
Löschen Sie die Logs nicht zu oft. Sie sind für die Fehleranalyse durch den Support sehr wichtig, falls einmal etwas nicht funktioniert.
::

## Fahrzeugcache leeren

Es kann vorkommen, dass der EinsatzMonitor noch Fahrzeuge anzeigt, die in der Connect-Organisation nicht mehr existieren. In diesem Fall leeren Sie den Fahrzeugcache direkt im EinsatzMonitor – ein SQLite-Browser ist dafür nicht nötig:

1. Öffnen Sie **Einstellungen → Connect Verbindung**
2. Klicken Sie auf **Verbindung Testen** (erst danach ist der Bereich „Wartung“ freigeschaltet)
3. Klicken Sie im Bereich **Wartung** auf **Fahrzeugcache leeren**
4. Nach der Meldung „Fertig bitte neustarten“ starten Sie den EinsatzMonitor neu

Weitere Informationen finden Sie unter [Connect-Verbindung](/einsatzmonitor/einstellungen/connect).

## User-Cache löschen

Um den Cache der Connect-Benutzer zu leeren, öffnen Sie die Datenbank wie oben beschrieben im DB Browser for SQLite und führen Sie folgendes SQL-Statement aus:

```sql
delete from ConnectUserCache
```

Schreiben Sie anschließend die Änderungen in die Datenbank (**Datei → Änderungen schreiben**), schließen Sie den DB Browser for SQLite und starten Sie den EinsatzMonitor neu.

## Regelmäßige Sicherung

Statt manueller Kopien können Sie im EinsatzMonitor ein tägliches automatisches [Backup](/einsatzmonitor/einstellungen/backup) der Datenbank einrichten.
