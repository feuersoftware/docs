Diese Anleitung zeigt Ihnen, wie Sie den EinsatzMonitor mit Feuersoftware Connect verbinden.

## Voraussetzungen

- [ ] Sie haben Zugang zum [Connect-Portal](https://connect.feuersoftware.com)
- [ ] Der EinsatzMonitor ist installiert und gestartet
- [ ] Eine Internetverbindung besteht

## Schritt 1: Einsatz-Monitor Account in Connect anlegen

1. Melden Sie sich im [Connect-Portal](https://connect.feuersoftware.com) an
2. Wählen Sie in Ihrem **Standort** den Menüpunkt **Geräte**
3. Klicken Sie auf **Neuer Einsatz-Monitor Account**
4. Geben Sie dem neuen Gerät einen aussagekräftigen **Namen** und klicken Sie auf **Neu**. Der Name wird später zur Verwaltung und Überwachung des Geräts im Connect-Portal angezeigt.
5. Sie erhalten eine E-Mail an Ihre eigene E-Mail-Adresse mit den Zugangsdaten (Benutzername und Passwort) des Einsatz-Monitor Accounts

## Schritt 2: Zugangsdaten im EinsatzMonitor eintragen

1. Öffnen Sie im EinsatzMonitor die **Einstellungen**
2. Wählen Sie den Menüpunkt **Connect Verbindung**
3. Tragen Sie **Benutzername** und **Passwort** aus der E-Mail ein
4. Klicken Sie auf **Verbindung Testen**. Der Button zeigt anschließend „Verbindung erfolgreich“ bzw. „Verbindung fehlgeschlagen“ an.

::callout{type="info"}
Erst nach einem erfolgreichen Test werden die Schaltflächen unter „Synchronisation“ und „Wartung“ freigeschaltet.
::

## Schritt 3: Verbindung aktivieren

1. Setzen Sie nach dem erfolgreichen Test den Schalter **Connect aktiv** auf aktiv
2. Beenden Sie den EinsatzMonitor und starten Sie ihn anschließend neu

::callout{type="warning"}
Die Anmeldung an Connect erfolgt erst beim Start des EinsatzMonitors. Ohne Neustart wird die Verbindung nicht aufgebaut.
::

## Schritt 4: Verbindung prüfen

Wurde die Verbindung erfolgreich hergestellt, sehen Sie im Connect-Portal beim Gerät den Status **„Wird ausgeführt“**.

## Einsätze über Connect empfangen

::callout{type="warning"}
Wichtig für Kunden mit einer Leitstellenschnittstelle: Werten Sie die Einsatzdaten nicht direkt am Monitor aus, sondern empfangen sie über Connect, müssen Sie zusätzlich den Schalter **Einsätze von Connect empfangen** aktivieren. Details siehe [Connect-Verbindung](/einsatzmonitor/einstellungen/connect).
::

## Fehlerbehebung

### Verbindung fehlgeschlagen

1. Prüfen Sie die Internetverbindung
2. Prüfen Sie Benutzername und Passwort aus der E-Mail
3. Stellen Sie sicher, dass die Firewall `connect.feuersoftware.com` nicht blockiert

```bash
# Test der Erreichbarkeit (in CMD/PowerShell)
ping connect.feuersoftware.com
```

4. Starten Sie den EinsatzMonitor nach Änderungen an den Connect-Einstellungen neu
