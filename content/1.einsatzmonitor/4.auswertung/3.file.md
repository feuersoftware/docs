# File-Auswertung

Mit der File-Überwachung empfängt der EinsatzMonitor Einsatzinformationen aus Dateien. Dazu wird ein Ordner auf der lokalen Festplatte überwacht. Neue Dateien werden innerhalb von **5 Sekunden** verarbeitet. So lassen sich Einsatzinformationen von Drittanbieter-Programmen auswerten, z. B. von OCR-Programmen bei der **Faxauswertung**.

---

## Aktivieren

**Auswertung → File Überwachung**

![Menü Auswertung mit dem Eintrag File Überwachung](/images/einsatzmonitor/einsatzmonitor_file_menue.png)

Schalten Sie den Schalter ein und starten Sie den EinsatzMonitor neu.

![Schalter der File Überwachung](/images/einsatzmonitor/einsatzmonitor_file_schalter.png)

::callout{type="warning"}
Die File-Überwachung startet nur beim Programmstart. Nach dem Aktivieren ist ein **Neustart** des EinsatzMonitors nötig.
::

---

## Ordner

Der EinsatzMonitor legt beim Start automatisch folgende Ordner unter `C:\Users\<Benutzername>\Einsatz_Monitor` an:

| Ordner | Beschreibung |
|---|---|
| **Text_Input** | Dieser Ordner wird überwacht. **Jede** hier abgelegte Datei wird als Text gelesen und verarbeitet. |
| **Text_Archiv** | Hier werden bereits verarbeitete Dateien abgelegt. Sie werden dabei mit Datum und Uhrzeit umbenannt. |

![Ordner Text_Input und Text_Archiv im Verzeichnis Einsatz_Monitor](/images/einsatzmonitor/einsatzmonitor_file_ordner.png)

Die Zeichenkodierung der Dateien wird automatisch erkannt.

::callout{type="info"}
Legen Sie nur Dateien mit dem Alarmtext in **Text_Input** ab. Eine Prüfung der Dateiendung findet nicht statt.
::

---

## Weitere Einstellungen

- **Blocker TextInput** unter [Einstellungen → Einsatz](/einsatzmonitor/einstellungen/allgemein): Während der eingestellten Zeit (0–600 Sekunden) werden neue Dateien **ohne Auswertung** direkt archiviert.
