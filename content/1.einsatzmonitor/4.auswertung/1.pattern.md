# Pattern

Ein Pattern ist eine Vorlage, die dem EinsatzMonitor erklärt, **an welcher Stelle im Alarmtext welche Information steht**. Pattern sind die am häufigsten genutzte Art, Einsatzdaten auszuwerten – egal ob der Text per E-Mail, File/Fax, Netzwerk, DME oder TETRA-SDS eingeht.

## Pattern öffnen

**Auswertung → Pattern - Standard**

Es öffnet sich das Fenster **Pattern Auswertung**.

---

## Pattern erstellen

1. Einsatztext einfügen.
2. Inhalt markieren und per **Rechtsklick** durch den entsprechenden Platzhalter ersetzen.
3. Mit **Testen** prüfen, welche Werte ausgewertet werden. Das Ergebnis erscheint in einer Tabelle mit **Schlüssel** und **Wert**.

Weitere Elemente im Pattern-Editor:

| Element | Beschreibung |
|---|---|
| **Zurück / Weiter** | Blättert durch die bereits empfangenen Einsatztexte. |
| **Testen** | Wertet den Einsatztext mit dem Pattern aus; das Ergebnis erscheint in der Tabelle **Schlüssel / Wert**. |
| **Fehler finden** | Unterstützt bei der Fehlersuche, wenn ein Pattern nicht wie erwartet auswertet. |
| **Separator** | Optionales Trennzeichen. Ist ein Separator gesetzt, erfassen die Datenplatzhalter sowie `{{WORTODERZAHL}}` und `{{BELIEBIGERINHALT}}` alles **außer** dem Separator. |
| **YouTube Tutorial** | Öffnet ein Video-Tutorial zur Pattern-Erstellung. |

::callout{type="info"}
Damit ein Text unter **Einsatztext** angezeigt wird, muss der Einsatz zuerst einmal durch den EinsatzMonitor gelaufen sein. Nach einem Neustart ist er dort sichtbar.
::

## Platzhalter

Platzhalter werden immer in doppelten geschweiften Klammern geschrieben: `{{NAME}}`. Groß- und Kleinschreibung spielt beim Abgleich keine Rolle.

### Datenplatzhalter

| Menütext | Platzhalter |
|---|---|
| Einsatzstichwort | `{{EINSATZSTICHWORT}}` |
| Einsatznummer | `{{EINSATZNUMMER}}` |
| Einsatzbeginn | `{{EINSATZBEGINN}}` |
| Sachverhalt | `{{SACHVERHALT}}` |
| Ort | `{{ORT}}` |
| Ortsteil | `{{ORTSTEIL}}` |
| Straße | `{{STRASSE}}` |
| Hausnummer | `{{HAUSNUMMER}}` |
| Position-Latitude | `{{LATITUDE}}` (nur Ziffern, `,` und `.`) |
| Position-Longitude | `{{LONGITUDE}}` |
| Position-Rechtswert | `{{RECHTSWERT}}` |
| Position-Hochwert | `{{HOCHWERT}}` |
| UTM-Position | `{{UTMCOORDINATES}}` |
| Segment | `{{SEGMENT}}` |
| Objekt | `{{OBJEKT}}` |
| RIC / SCHLEIFE | `{{RIC}}` |
| GMA | `{{GMA}}` |
| Meldender | `{{MELDENDER}}` |
| Meldender Telefonnummer | `{{MELDENDER_TELEFON}}` |
| Zusatzinformation 1 / 2 / 3 | `{{ZUSATZFELD1}}`, `{{ZUSATZFELD2}}`, `{{ZUSATZFELD3}}` |
| AAO | `{{AAO}}` |

### Zusatzinformationen benennen

Die Zusatzinformationen können eine eigene Bezeichnung erhalten:

```
{{ZUSATZFELD1:Bezeichnung}}
```

Ohne eigene Bezeichnung heißt das Feld „Zusatzinformation 1“, „Zusatzinformation 2“ usw. Die Ziffer 1–3 steht für die Priorität: Gibt es zu viele Zusatzinformationen, entscheidet die Priorität, welche Information angezeigt wird.

### Hilfsplatzhalter

Hilfsplatzhalter „schlucken“ Textbereiche, Zahlen oder Sonderzeichen, die nicht angezeigt werden sollen.

| Menütext | Platzhalter | Verhalten |
|---|---|---|
| Platzhalter für beliebige Inhalte | `{{BELIEBIGERINHALT}}` | Nimmt so viele Zeichen wie möglich auf – egal welche, auch Zeilenumbrüche. |
| Platzhalter für Sonderzeichen | `{{SONDERZEICHEN}}` | Nimmt **beliebig viele (auch keine)** Sonderzeichen inklusive umgebender Leerzeichen auf. |
| Platzhalter für Zahlen | `{{ZAHL}}` | Nimmt eine Zahl beliebiger Größe auf. Komma und Punkt gehören zur Zahl, ein vorangestelltes Minus ist erlaubt. Andere Zeichen wie ein Doppelpunkt trennen die Zahl ab. |
| Platzhalter für Wörter oder Zahlen | `{{WORTODERZAHL}}` | Nimmt ein Wort oder eine Zahl auf (Buchstaben, Ziffern und `_`). Leerzeichen und Satzzeichen beenden den Platzhalter. |

::callout{type="info"}
Gerade bei der Faxauswertung kann es passieren, dass ein Doppelpunkt als Semikolon erkannt wird. Mit `{{SONDERZEICHEN}}` sparen Sie sich, für jede Variante ein eigenes Pattern zu bauen.
::

### Beispiele

| Text im Alarm | Pattern |
|---|---|
| `Einsatzstichwort: Feuer klein` | `Einsatzstichwort{{SONDERZEICHEN}}{{EINSATZSTICHWORT}}` |
| `Uhrzeit: 22:30` | `Uhrzeit{{SONDERZEICHEN}}{{ZAHL}}{{SONDERZEICHEN}}{{ZAHL}}` |

## Punktelogik

Bei jedem eingehenden Einsatztext werden **alle** angelegten Pattern ausprobiert. Für jedes gefüllte Feld und jede Zusatzinformation erhält ein Pattern Punkte. Verwendet wird das Pattern mit der **höchsten Punktzahl** – damit wird immer das Pattern genommen, das die meisten Informationen ausgewertet hat. Bei Punktgleichstand bleibt das zuerst getroffene Pattern.

Sie können also mehrere Pattern für unterschiedliche Alarmtexte (z. B. verschiedene Leitstellen-Formate) parallel anlegen.

## Tabellenauswertung (SECURECAD)

Die Tabellenauswertung (**Auswertung → Tabelle - Securecad**) wurde speziell für „SECURECAD“-E-Mails entwickelt, deren Aufbau sich stark unterscheiden kann. Sie wird verwendet, wenn **kein Pattern angelegt** ist.

::callout{type="info"}
Mit dem Schalter **Nur Patternauswertung** unter [Einstellungen → Einsatz](/einsatzmonitor/einstellungen/allgemein) wird die Tabellenauswertung abgeschaltet. Ist bei der [E-Mail-Auswertung](/einsatzmonitor/auswertung/e-mail) **RLP XML** aktiv, werden Pattern und Tabellenauswertung übersprungen.
::

## Tipps

- Platzhalter versuchen immer, so viele Zeichen wie möglich zu „schlucken“ – wie eine kleine Raupe Nimmersatt. Begrenzen Sie Platzhalter deshalb durch festen Text oder einen **Separator**.
- Leerzeichen, die von einem Platzhalter „geschluckt“ wurden, werden am Anfang und am Ende automatisch entfernt.
- Nehmen Sie sich für die Einrichtung genug Zeit. Die Auswertung ist der aufwendigste Schritt und hängt stark von den empfangenen Daten ab.
- Prüfen Sie jedes Pattern mit **Testen** an mehreren echten Einsatztexten (über **Zurück / Weiter**).
