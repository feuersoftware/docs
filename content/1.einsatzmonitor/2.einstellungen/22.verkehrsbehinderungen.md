# Verkehrsbehinderungen

Im EinsatzMonitor können Verkehrsbehinderungen eingetragen werden, um Einsatzkräfte zu informieren. Sie werden in der **Einsatzansicht auf der Routenkarte** sowie im **Standby als Standbyelement** angezeigt. Die Einträge werden ausschließlich lokal im EinsatzMonitor gepflegt.

## Verkehrsbehinderung anlegen

1. Einstellungen des EinsatzMonitors öffnen
2. Menüpunkt **„Verkehrsbehinderungen"** wählen
3. Informationen eintragen und den Ort auf der Karte festlegen
   - Ort suchen: Suchfeld über der Karte
   - Karte verschieben: rechte Maustaste gedrückt halten
   - Marker hinzufügen: Doppelklick auf das rote Kreuz oder Klick auf das grüne Kreuz links der Karte
   - Marker löschen: rotes X links der Karte
4. Mit **„Verkehrsbehinderung speichern"** bestätigen

![EinsatzMonitor Verkehrsbehinderungen](/images/einsatzmonitor/EM_Verkehrsbehinderung.jpg)

| Feld | Beschreibung |
|---|---|
| **Beschreibung** | Text zur Behinderung (z. B. „Baustelle, Fahrbahn nur einspurig") |
| **Marker Bild** | Symbol, mit dem die Behinderung auf der Karte dargestellt wird (derzeit „Baustelle“) |
| **Startdatum** | Ab wann die Behinderung gilt |
| **Enddatum** | Bis wann die Behinderung gilt |

Pro Verkehrsbehinderung können mehrere Marker gesetzt werden. Die Anzahl der gesetzten Marker wird angezeigt („x Marker angelegt“).

## Anzeige

Angezeigt werden nur Verkehrsbehinderungen, deren Zeitraum (Start- bis Enddatum) den aktuellen Tag einschließt.

### Im Standby

Fügen Sie in den [Standbyelementen](/einsatzmonitor/einstellungen/standbyelemente) das Element **„Verkehrsbehinderungen"** hinzu. Die Einträge werden als Text mit Zeitraum und Beschreibung dargestellt (maximal 8 Einträge).

![Standbyelement Verkehrsbehinderungen](/images/einsatzmonitor/einsatzmonitor_verkehrsbehinderungen_standby.png)

### In der Einsatzansicht

Die Verkehrsbehinderung wird als Symbol auf der Routenkarte eingeblendet. Da die Routenkarte auch als `routenmap.png` für den [Ausdruck](/einsatzmonitor/howtos/drucken) verwendet wird, erscheint das Symbol auch dort.

![Verkehrsbehinderung als Baustellensymbol auf der Routenkarte](/images/einsatzmonitor/einsatzmonitor_verkehrsbehinderungen_routenkarte.png)
